# Buzz integration screenshots

Real captures of Checkmark inside the Buzz grading view, taken from the
`riverview-demo` tenant on dev (Riverview High School / U.S. History 11 -
Period 3 / Marcus Ellery). Every `<Screenshot>` on this site is a real product
capture; do not substitute mock-ups.

| file | what it shows |
|---|---|
| `cq-report-in-buzz.png` | Custom Question report in the Buzz grader: all five tiles (Overall / Pasted / Transcribed / Uncited / AI), highlighted essay, Plagiarism Breakdown sidebar. |
| `cq-playback.png` | Playback mid-replay over the same submission. |
| `essay-report-in-buzz.png` | Native Buzz essay question: report beside Buzz's own rubric and Feedback editor. Note only three tiles, no Pasted / Transcribed / Playback, which is the point of the comparison. |
